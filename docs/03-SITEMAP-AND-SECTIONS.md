- Establish product type and responsible positioning.

- Use responsibly

## 3. Outcome rail

A horizontal or responsive strip showing:

- Research faster
- Organize consistently
- Reduce repetitive copying
- Prepare better outreach

This should not use fake metrics.

## 4. Problem-to-outcome section

Headline:
**Prospecting should not feel like manual data entry.**

Show the old workflow:
- Search
- Open listing
- Copy details
- Change tabs
- Paste into sheet
- Repeat

Show the LeadOrbiq workflow:
- Search
- Select
- Organize
- Review
- Export or continue outreach

Use a split-screen transformation or before-and-after workflow.

## 5. How it works

Four steps:

1. Search your target market
2. Review relevant businesses
3. Collect and organize lead details
4. Use the list in your outreach workflow

Create a sticky visual that changes with the active step.
