# LeadOrbiq Website — Claude Code Package

This package is a complete build brief for a premium website for the **LeadOrbiq Chrome extension**.

## Required framework

Use the same architecture as the Inoviqa website:

- Astro
- TypeScript
- Tailwind CSS
- Astro Content Collections
- Static Site Generation
- Vite
- Reusable Astro components
- Minimal React islands only when truly necessary

## How to use

1. Copy the `docs` folder into the LeadOrbiq project root.
2. Open the repository in Claude Code.
3. Send Claude the contents of `00-CLAUDE-CODE-MASTER-PROMPT.md`.
4. Claude must read all supporting Markdown files before changing code.
5. Replace all `[VERIFY]`, `[PLACEHOLDER]`, and `[INSERT_...]` values before launch.
