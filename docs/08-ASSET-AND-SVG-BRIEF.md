# Asset and SVG Brief

## Main rule

Create original product visuals by code. Do not rely on stock photography.

## Required brand assets

Create:

- LeadOrbiq icon mark
- Horizontal wordmark
- Monochrome logo
- Light-theme logo
- Dark-theme logo
- Favicon
- Social preview composition
- Simple loading mark

If an approved LeadOrbiq logo already exists in the repository, preserve and use it rather than replacing it.

## Logo direction

Combine two or three ideas:

- Orbit
- Location pin
- Lead node
- Letter L
- Letter O
- Circular scanning
- Connected point

Keep the icon:

- Recognizable at 16px
- Simple enough for a Chrome extension icon
- Balanced in a square
- Free from tiny details
- Theme compatible
- Original

Do not imitate the Google Maps logo.

## Hero visual

Create a responsive code-based composition.

Layers:

1. Abstract map grid
2. Fictional search-result column
3. LeadOrbiq browser-extension panel
4. Selected business cards
5. Structured lead table
6. Export or next-step tray `[VERIFY]`
7. Orbiting brand nodes
8. Cursor path or guided collection animation

Use fictional data such as:

- Northline Plumbing
- ClearFlow Septic
- Summit Crawlspace
- Greenway Drainage
- Harbor Pump Service

Do not use real company contact data.

## Product visuals

Create reusable components for:

### Map Search Visual

Shows:
- Search phrase
- City
- Location markers
- Result cards
- Selected state

### Extension Panel Visual

Shows:
- Lead count
- Selected entries
- Collection status
- Clear actions
- Settings or field selector only when verified

### Lead Table Visual

Shows:
- Structured rows
- Column consistency
- Review state
- Fictional business information

### Workflow Visual

Shows:
- Search
- Select
- Organize
- Review
- Outreach

### Comparison Visual

Shows manual copy-and-paste fragments becoming organized rows.

## SVG style

- Rounded geometry
- 1.5px–2px visual stroke
- Gradient used selectively
- Theme-aware fills
- Minimal filter effects
- No massive SVG markup
- Reusable symbols where appropriate
- Descriptive title only when informational
- `aria-hidden="true"` when decorative

## Background decorations

Possible elements:

- Orbital rings
- Map-coordinate grid
- Soft data particles
- Luminous route lines
- Scanning radius
- Fine noise layer
- Edge glow

These must remain secondary to the content.

## Motion concepts

- Markers enter a search radius
- Selected cards slide toward the extension panel
- Rows settle into a structured table
- Orbit line pulses after successful collection
- Export tray confirms completion `[VERIFY]`
- Section rail follows scroll progress

Keep motion subtle and reversible.

## Social preview

Create a 1200 × 630 composition:

- LeadOrbiq mark
- Product name
- Short headline
- Abstract map
- Extension panel
- Brand gradient
- Strong contrast
- Large readable text

Suggested headline:

**Turn Google Maps searches into organized lead lists**

## Image accessibility

- Product diagrams need concise alt text when informational
- Complex visuals need nearby text explanation
- Decorative glows and grids must be hidden from screen readers
- Do not repeat the same information in alt text and adjacent copy
