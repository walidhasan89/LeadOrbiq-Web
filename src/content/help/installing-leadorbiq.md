LeadOrbiq is distributed through the Chrome Web Store as a browser extension. There's no separate desktop app or account setup required just to install it.

## Before you install

Every Chrome extension requests a set of permissions when you install it. Review these permissions in the Chrome Web Store listing before adding LeadOrbiq, the same way you would for any extension. If a permission doesn't make sense for what the extension does, that's worth asking about before you proceed.

## Installing the extension

1. Open the LeadOrbiq listing in the Chrome Web Store using the **Add to Chrome** button on this site.
2. Review the requested permissions.
3. Confirm the installation.
4. Pin the extension to your toolbar so it's easy to reach while browsing Google Maps.

## After installing

Once installed, LeadOrbiq is designed to work alongside your normal Google Maps browsing rather than replacing it — you search and browse the way you normally would, and the extension helps with the collection and organization side of the workflow.

## Supported browsers

LeadOrbiq is built as a Chrome extension. Compatibility with other Chromium-based browsers has not been confirmed. If you use a different browser day-to-day, check the Chrome Web Store listing for current compatibility details.
